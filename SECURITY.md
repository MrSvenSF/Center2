# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen werden grundsätzlich für die aktuelle stabile Version von
MHCenter2 bereitgestellt.

| Version | Unterstützt |
| --- | --- |
| 1.0.x | ✅ |
| ältere Versionen | ❌ |

## Sicherheitslücken melden

Wenn du eine mögliche Sicherheitslücke findest, veröffentliche bitte nicht sofort
alle Details in einem öffentlichen GitHub Issue.

Dazu gehören insbesondere Probleme wie:

- Umgehung von Permissions
- unberechtigter Zugriff auf Daten
- SQL- oder Datenbankprobleme
- unsichere Netzwerkkommunikation
- Remote-Actions, die von unberechtigten Systemen ausgelöst werden können
- unbeabsichtigte Offenlegung sensibler Informationen

Bitte versuche zunächst, mich privat zu kontaktieren.

Du kannst mich über meinen Discord erreichen:

https://discord.gg/xDzGEp5NzE

Beschreibe möglichst:

- betroffene MHCenter2-Version
- Auswirkungen der Schwachstelle
- Schritte zur Reproduktion
- relevante Logs oder Codebereiche
- mögliche Lösungsvorschläge, falls vorhanden

Bitte veröffentliche keine Zugangsdaten, Passwörter oder andere vertrauliche
Informationen.

## Reaktion auf Meldungen

Ich versuche Sicherheitsmeldungen so schnell wie möglich zu prüfen.

Da MHCenter2 ein privat gepflegtes Open-Source-Projekt ist, kann keine feste
Reaktions- oder Behebungszeit garantiert werden.
