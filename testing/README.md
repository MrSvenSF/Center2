# Testbereiche

Dieser Ordner bündelt die Entwicklungs- und Beispielumgebungen von MHCenter2.

| Ordner | Veröffentlichung | Zweck |
|---|---|---|
| `PaperTestModule/` | ja | kleines Beispiel für die Paper-Modul-API |
| `VelocityTestModule/` | ja | kleines Beispiel für die Velocity-Modul-API |
| `MinecraftTestNetwork/` | nein | lokale Laufzeitumgebung mit Velocity und zwei Paper-Servern |

Das Minecraft-Testnetzwerk enthält Serverdateien und Laufzeitdaten und wird
durch `.gitignore` vollständig vom Repository ausgeschlossen.
