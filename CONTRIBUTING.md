# Zu MHCenter2 beitragen

Danke für dein Interesse an MHCenter2!

Beiträge, Fehlermeldungen und Verbesserungsvorschläge sind willkommen.

## Bugs melden

Wenn du einen Fehler findest, erstelle bitte ein GitHub Issue und beschreibe möglichst genau:

- verwendete MHCenter2-Version
- Paper- oder Velocity-Version
- Java-Version
- was du erwartet hast
- was tatsächlich passiert ist
- relevante Fehlermeldungen oder Logs
- Schritte, mit denen sich der Fehler reproduzieren lässt

Bitte entferne Passwörter, Zugangsdaten und andere sensible Informationen aus Logs.

## Vorschläge und neue Funktionen

Feature-Vorschläge können ebenfalls über GitHub Issues eingereicht werden.

Beschreibe dabei:

- welches Problem gelöst werden soll
- wie du dir die Funktion vorstellst
- warum sie für MHCenter2 sinnvoll wäre

Nicht jeder Vorschlag wird automatisch umgesetzt.

## Pull Requests

Pull Requests sind willkommen.

Bitte:

1. Arbeite auf Basis des aktuellen `main`-Branches.
2. Halte Änderungen möglichst auf ein Thema beschränkt.
3. Ändere keine unrelated Funktionen.
4. Verwende Maven für Builds und Tests.
5. Führe vorhandene Tests vor dem Pull Request aus.
6. Ergänze Tests, wenn sich Verhalten ändert.
7. Dokumentiere relevante Änderungen.

MHCenter2 verwendet Java 25.

## Größere Änderungen

Bei größeren Änderungen oder neuen APIs bitte zuerst ein Issue eröffnen.

So kann vor der Implementierung geklärt werden, ob die Änderung zum Projekt passt.

## KI-Unterstützung

Beiträge dürfen mit KI-Unterstützung erstellt werden.

Der Einreicher bleibt jedoch dafür verantwortlich, den eingereichten Code zu prüfen,
zu verstehen und sicherzustellen, dass keine fremden Lizenzrechte verletzt werden.

## Lizenz

Mit dem Einreichen eines Beitrags erklärst du dich damit einverstanden, dass dein
Beitrag unter der Apache License 2.0 des Projekts veröffentlicht wird.
